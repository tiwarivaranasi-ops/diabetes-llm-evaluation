# Scoring Rubric

Each of the 32 questions was scored from 0 to 3, giving a maximum possible score of 96.

| Score | Classification | Criteria |
|---:|---|---|
| 0 | Incorrect answer | Incorrect answer, regardless of the explanation provided. |
| 1 | Correct answer only | Correct answer, but explanation is absent, incorrect, or does not adequately justify the answer. |
| 2 | Correct answer + explanation | Correct answer with a correct and adequate explanation consistent with the gold-standard answer. |
| 3 | Correct answer + explanation + additional point | Correct answer with an adequate explanation plus an additional correct and relevant point that meaningfully adds to the answer. |

**Percentage score = (Total score obtained ÷ 96) × 100.**
