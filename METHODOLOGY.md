# Methodology and Testing Protocol

## Evaluation setting

Each AI system was evaluated through its standard consumer-facing interface. Web retrieval/search was permitted when available to reflect typical real-world use rather than isolated model knowledge.

## Access conditions

All assistants were evaluated using freely available access. Logged-out access was used where possible. Where a platform required authentication, a free account was used. No paid model or premium feature was intentionally selected.

## Test procedure

The 32-question set and gold-standard answers were finalized before scoring.

Each question was submitted independently in a fresh conversation/window.

No previous question, model response, hint, correction, or gold-standard answer was supplied as context.

The first complete response was recorded.

Responses were scored against the predefined rubric.

Each system could obtain a maximum of 3 points per question and 96 points overall.

Percentage score was calculated as total score / 96 × 100.

## Evaluation date

9 August 2026.

## Reference standard

Gold-standard answers were prepared primarily from the American Diabetes Association Standards of Care in Diabetes—2026, with page-level references recorded in the source document. Some items explicitly allowed alternative answers when supported by a defensible guideline or high-quality study.
